SEC.00 — INTRO

معرفی سیستم

یک دیزاین سیستم خود-کافی برای Agent هوش مصنوعی — بر اساس سه زبان طراحی: نئوبروتالیسم مونوکروم، تایپوگرافی سوئیسی، و استتیک بلوپرینت.

خام، نه ساده

هر جزء باید «نیمه‌تمام» و کاربردی به نظر برسد — بدون پرداختِ بیش‌ازحد، بدون glassmorphism، بدون gradient.

سخت، نه نرم

سایه‌ها همگی آفست و بدون blur هستند. بوردرها نازک (1–1.5px). شعاع تقریباً صفر. تعامل‌ها snap.

تک‌رنگ، نه سرد

پالت مونوکروم با یک رنگ تاکیدی پنهان (همان foreground). هیچ رنگ آبی/قرمز/سبزی در خودِ UI نیست.

تایپوگرافی قهرمان

تیترها با فونت نمایشی غول‌پیکره (Lalezar) تا 150px+. بدنهٔ متن Vazirmatn. برچسب‌های فنی JetBrains Mono.

پالت نمونه dark + light

SEC.10 — CUSTOM CURSOR

کرسر سفارشی

نقطهٔ سفید + حلقهٔ دنباله‌رو با mix-blend-mode: difference. فقط در دسکتاپ (pointer:fine).

پیاده‌سازی JS + CSS 
// فعال‌سازی
if (matchMedia('(pointer:fine)').matches) {
  document.body.classList.add('has-cursor');
  let x = innerWidth/2, y = innerHeight/2, rx = x, ry = y;
  addEventListener('mousemove', e => { x = e.clientX; y = e.clientY });
  (function loop() {
    rx += (x - rx) * .16;
    ry += (y - ry) * .16;
    dot.style.transform = `translate(${x}px, ${y}px)`;
    ring.style.transform = `translate(${rx}px, ${ry}px)`;
    requestAnimationFrame(loop);
  })();
}

// CSS
.cursor-dot, .cursor-ring {
  position: fixed; border-radius: 50%;
  pointer-events: none; mix-blend-mode: difference;
}
.cursor-dot { width:7px; height:7px; background:#fff }
.cursor-ring { width:36px; height:36px; border:1.5px solid #fff }

SEC.35 — AGENT PROMPT

پرامپت مرجع Agent

این متن را به Agent بدهید تا همان زبان طراحی را دقیقاً بازسازی کند.

System Prompt
شما یک طراح/توسعه‌دهندهٔ Front-end هستید که همیشه از این دیزاین سیستم استفاده می‌کند:

نام سبک: «نئوبروتالیسم مونوکروم + تایپوگرافی سوئیسی + استتیک بلوپرینت»

قواعد اجباری:
1) پالت مونوکروم: فقط از متغیرهای --bg, --fg, --mut, --line استفاده کن.
   هیچ رنگ آبی/سبز/قرمز خام در UI نباشد.
2) بدون blur، بدون glassmorphism، بدون gradient (مگر در media placeholder).
3) سایه‌ها همه سخت و آفست: box-shadow: X Y 0 var(--shadow) — نه drop-shadow.
4) border-radius: 0 مگر برای chip/toggle که pill.
5) بوردرها: 1px (hair) / 1.5px (thin) / 2px (thick).
6) هر تعامل هاور: اینورت fg/bg + سایهٔ سخت + شیفت -2px,-2px.
7) تایپوگرافی: Lalezar برای تیترهای قهرمان، Vazirmatn برای بدنه، JetBrains Mono برای برچسب‌های فنی.
8) قبل از هر عنوان سکشن، یک kicker مونو با مربع 9px.
9) گرید مهندسی 72px به‌عنوان ::before در body با opacity 5%.
10) لایهٔ grain ثابت با opacity 5%.
11) کرسر سفارشی با mix-blend-mode: difference در دسکتاپ.
12) RTL native: از inset-inline و text-align: start استفاده کن.
13) اعداد فارسی در UI عمومی، انگلیسی در URL/کد.
14) پشتیبانی prefers-reduced-motion.
15) تم تاریک/روشن از طریق data-theme روی html.

کامپوننت‌های استاندارد:
.btn, .btn--solid, .btn--ghost, .btn--icon
.chip, .tag
.kicker, .link, .link--mono
.input, .textarea, .field, .check, .toggle
.badge, .badge--live, .avatar
.card, .spec
.row (با invert-on-hover)
.accordion, .tabs, .dropdown
.ds-table, .bar, .loop
.modal-backdrop, .toast
.ticker (marquee), .orbit (SVG textPath), .scroll-hint, .divider

قبل از تولید هر HTML، این متغیرها را در :root تعریف کن:
--bg, --bg2, --bg3, --card, --card2,
--fg, --fg2, --mut, --mut2,
--line, --line2, --line3, --grid-c, --shadow,
--f-body, --f-disp, --f-mono,
--fs-xs...--fs-5xl, --lh-* ,
--s-1...--s-9, --grid, --bw-hair, --bw-thin, --bw-thick,
--sh-hair, --sh-sm, --sh-md, --sh-lg, --sh-xl,
--ease, --ease-spring, --dur-fast, --dur-mid, --dur-slow.
